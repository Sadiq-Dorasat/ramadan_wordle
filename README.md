# Ramadan Wordle

A Ramadan-themed version of the popular word-guessing game Wordle. Guess the 5-letter Islamic word in six tries or less!

## Features

- Daily Islamic-themed words
- Word definitions to learn more about Islamic terms
- Statistics tracking to monitor your progress
- Share your results with friends
- Mobile-friendly design

## How to Play

1. Guess any 5-letter word to start
2. After each guess, the color of the tiles will change:
   - 🟩 Green: The letter is correct and in the right position
   - 🟨 Yellow: The letter is in the word but in the wrong position
   - ⬛ Gray: The letter is not in the word
3. Keep guessing until you find the word or run out of attempts
4. A new word is available each day

## Technical Details

This game is built with vanilla JavaScript, HTML, and CSS. It features:

- Local storage for saving game progress and statistics
- Responsive design for all device sizes
- Shareable results with emoji grid representation
- Daily word rotation based on the date
